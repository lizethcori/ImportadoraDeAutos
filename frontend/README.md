# Frontend - Importadora Nissan

## Estructura
- `pages/` - Páginas HTML principales
- `assets/` - Recursos estáticos
  - `css/` - Hojas de estilo
  - `js/` - Archivos JavaScript
  - `images/` - Imágenes

## Páginas
- `index.html` - Login principal
- `dashboard-admin.html` - Dashboard administrador
- `dashboard-cliente.html` - Dashboard cliente
- `dashboard-vendedor.html` - Dashboard vendedor
- `catalogo.html` - Catálogo de vehículos

## Estilos
- `main.css` - Estilos generales
- `login.css` - Estilos del login
- `dashboard.css` - Estilos de dashboards

## JavaScript
- `main.js` - Lógica principal
- `auth.js` - Sistema de autenticación
- `dashboard.js` - Lógica de dashboards
